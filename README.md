# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** web game built using **HTML, CSS, and JavaScript**.

The player competes against the computer, which randomly selects Rock, Paper, or Scissors.

## ✨ Features

- 🎮 Play Rock Paper Scissors against the computer
- 🤖 Computer makes a random choice
- 🏆 Tracks user and computer scores
- 👤 Displays your selected move
- 💻 Displays the computer's move
- ✨ Sparkle effect when the player wins
- 🎨 Attractive sky-blue 3D UI
- 🔵 Circular Rock, Paper, and Scissor buttons
- 🖱️ Hover and click animations
- 📱 Responsive design for smaller screens

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
